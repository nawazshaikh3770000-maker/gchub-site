CSV Cleaning Pipeline

Version 1.0 · $25 · VERIFIED ON DISK

What it does

Command-line CSV cleaner. Resolves duplicates by a stated rule, normalises types and encoding, drops unparseable rows instead of guessing, and refuses to zero-fill a column it cannot honestly impute.

Features

  • Duplicate resolution with the rule written down
  • Type and encoding normalisation
  • Non-imputable columns flagged, never invented
  • Change log of every modification
  • Data dictionary output

Requirements

Node.js 18+ on any platform with a shell. No network access, no API keys.

Limitations

Not for files beyond roughly a million rows - it is synchronous by design

  • Does not infer semantics; it cleans, it does not decide what your columns mean
  • CSV only, not XLSX - convert first

Evidence

Run against live marketplace data containing duplicate rows, malformed rows, missing values and a non-imputable column. All handled as designed.
