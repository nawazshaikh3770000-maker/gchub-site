OpenAPI Documentation Generator

Version 1.0 · $35 · VERIFIED ON DISK

What it does

Validates an OpenAPI 3.x spec, then generates Markdown reference documentation from that same source, so the docs cannot drift from the schema.

Features

  • Spec validation that fails closed
  • Generated Markdown reference
  • Endpoint, parameter and response tables
  • Single source of truth

Requirements

Node.js 18+. A valid or invalid OpenAPI spec to run against.

Limitations

Generates from OpenAPI 3.x; Swagger 2.0 needs conversion first

  • Will not document an API that has no spec - I would have to write the spec, which is a different service

Evidence

Two tests: a valid spec produces correct Markdown; a malformed spec is rejected before any prose is written.
