Dry-Run-Safe Automation Engine

Version 1.0 · $40 · VERIFIED ON DISK

What it does

Runs task steps with real retry and timeout handling. Dry-run is the default, so you see what it would do before anything happens.

Features

  • Dry-run default
  • Retry with backoff on failure
  • Timeout handling that actually terminates
  • Per-step error reporting
  • No hardcoded secrets

Requirements

Node.js 18+. Adapt the step definitions to your own task.

Limitations

A step runner, not a scheduler - you trigger it

  • No queue, no distributed workers, no retry-forever semantics
